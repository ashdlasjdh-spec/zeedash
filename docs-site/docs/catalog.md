# Item catalog

Everything the Game portal can grant, verified against the live game (`lib/catalog.js`). Also browse
it in the panel on the public **Catalog** page.

Invincible · Nightwing · Catwoman · Black Power · Ghost · Reverse Flash · OP Katana.

Flash · Fly · Magic · Orange Flame · Purple Flame · Escape · River · Scorpion · Whip.
